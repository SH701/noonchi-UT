## 🚀 주요 기능

### 💬 ASK — 한국어 코치

내가 하려는 말이 한국어로 어떻게 들리는지 AI가 분석해줍니다.

- 대화 상대·친밀도에 따른 적절한 말투 추천
- 문화적 맥락 및 뉘앙스 설명
- 대안 표현 제시

### 🎭 Roleplay — AI 대화 연습

25개 시나리오를 통해 실제 상황에서 AI와 한국어 대화를 연습합니다.

- 실시간 스트리밍 대화
- AI의 속마음(숨겨진 의미) 표시
- 음성 입력(STT) 및 AI 응답 음성 재생(TTS)
- 대화 중 힌트 제공

### 📊 Report — 피드백 리포트

롤플레이 종료 후 AI가 대화를 분석해 리포트를 생성합니다.

- **Overall Evaluation**: 전반적인 대화 평가 요약
- **Politeness / Naturalness 점수**: 정중함과 자연스러움을 수치로 제공
- **Feedback 탭**: 대화 메시지별 피드백 확인
- **Detailed Metrics 탭**: 대화 요약 · 잘한 점 · 개선점 + 팁 제공
